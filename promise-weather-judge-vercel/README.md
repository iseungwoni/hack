# 약속 날씨 판결기 — 실제 API 연동 버전

기획안의 필수·선택 기능을 서버 함수(`api/judge.js`)로 구현했습니다.

## 구현 내용
- 기상청 단기예보(`getVilageFcst`) 조회: 강수확률·강수형태·기온(일 최고)·풍속, 발표 시각 표기
- 위경도 → 예보 격자(nx, ny) 변환: 서울 (60,127), 대전 (67,100)으로 검증함
- 에어코리아 시도별 실시간 측정값 평균으로 초미세먼지 산출
- 규칙 점수 계산(날씨 + 사정 유형 상한 + 중요도) 후 판결
- Claude가 맡는 일: 개인 사정 분류(입력 문장 속 지시는 따르지 않음), 판결문과 메시지 3종 생성
- 판결이 "실내로 변경"이면 관광정보 API로 근처 문화시설 후보 3곳 제안(선택)
- 무기력·우울 표현이 보이면 판결 대신 안부 문구
- 보안: API 키는 서버 환경변수에만, 개인 사정 문장은 저장하지 않음, 화면 출력은 textContent만 사용

## 배포
1. 이 폴더의 내용물(api, public, package.json)을 GitHub 저장소 맨 위(루트)에 올리고 Vercel에서 가져오기(Import)
2. Vercel 환경변수에 `.env.example`의 항목 등록 (`DATA_GO_KR_KEY`만 필수, `ANTHROPIC_API_KEY`는 선택)
3. 공공데이터포털에서 기상청 단기예보, 에어코리아 대기오염정보, (선택) 한국관광공사 국문 관광정보 서비스 활용 신청

## 제출 전 확인 (직접 확인 필요)
- 실제 API 키와 네트워크가 없어 이 환경에서는 호출 테스트를 하지 못했고, 문법과 격자 변환만 검증했습니다.
- 관광정보 API 주소(`TOUR_URL`)와 응답 형식은 공공데이터포털 상세 페이지 기준으로 확인하세요. 호출이 실패하면 후보 없이 판결만 나옵니다.
- 초미세먼지는 약속 시각 예측이 아니라 현재 측정값입니다. 화면에 그렇게 표기했습니다.
- 단기예보는 날짜가 멀수록 정밀도가 낮습니다. 조회 범위 밖이면 오류 메시지가 나옵니다.
- Claude 모델명은 `ANTHROPIC_MODEL`로 바꿀 수 있습니다.
